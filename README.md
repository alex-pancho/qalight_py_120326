# Програма курсу “QA Automation on Python”

# Блок1: Програмування на Python

1. Знайомство. Загальні відомості та все, щоб почати роботу
2. Робота з Git. Репозиторій Git Hub, як основа співпраці програмістів
3. Синтаксис, структура, ключові слова. Типи даних. Числові операції. Ввід/Вивід даних
4. Строки `str`: методи, атрибути та корисні трюки
5. Умови (`if/elif/else`) та цикли (`for/while`)
6. Колекції: `tuple`, `list`, `set`, `dict`
7. Створення і робота функцій (`def`)
8. Виключення та робота з ними(`try/except/finaly`). Використання `assert` у програмі
9. Робота з файлами, бібліотека `pathlib` та її модуль `Path`. Імпорт коду  (частина 1)
10. Практична обробка `csv, json, xml` файлів.

# Блок 2: Тестування та обєктно-орієнтований підхід.

11. Вступ у тестування на `pytest`. Імпорт коду (частина 2)
12. Вступ до ООП, Класи (`class`) та об'єкти, атрибути класу, наслідування.
13. Життєвий цикл класу. Магічні методи, інкапсуляція і поліморфізм. Області видимості змінних
14. Ітератори та генератори. Декоратори, створення декораторів.
15. Тестування REST API, частина 1: Робота з мережею. Бібліотеки `urllib` та `requests`. Запити `get, post, put, delete`
16. Тестування REST API, частина 2: Перевірка відповідності OASv3. End-2-End тестування. Структура тестувального фреймворку
17. SQL і Робота з реляційними базами даних (`sqlite3`, MySQL) Робота з базами даних через ORM (`SQLAlchemy`)
18. Дата і час (`time, datetime, timedelta`)
19. Використання патернів та декораторів(фікстур) у pytest. Параметризовані тести.
20. Парсинг даних у тестуванні. `XPath`, `CSS`-локатори. Регулярні вирази
21. Вступ у Selenium - робота з веб елементами. Налаштування роботи браузера. Віддалене виконання у Selenium Grid
22. Очікування на веб-елемент у WebDriver. Основи побудови PageObject
23. CI/CD на прикладі GitHub Actions (freestyle and pipeline)
24. Тестове інтерв'ю та лекція з настановами та рекомендаціями щодо пошуку роботи
